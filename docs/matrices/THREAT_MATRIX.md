# Threat Matrix

Scope: the v0.1 harness on a single trusted machine, with a local model runtime and a
synthetic (or later, real) application behind adapters. Likelihood assumes a competent
operator, an untrusted model output stream, and possibly untrusted data reaching the prompt.

Mitigation status: **D** = designed in and tested · **P** = partially mitigated, residual
recorded · **X** = explicitly deferred with a trigger.

## Threat-model assumptions

1. The operator's machine is not compromised by a privileged attacker; if it is, no
   local-only control in v0.1 is sufficient (stated explicitly, not hand-waved).
2. The model runtime is unauthenticated and localhost-bound (verified in R-12); the harness
   never exposes it further.
3. Configuration files are trusted inputs, reviewed like code.
4. Synthetic fixtures contain no real customer data, so data-protection threats are out of
   scope for v0.1 but are listed in the integration contract for the real system.
