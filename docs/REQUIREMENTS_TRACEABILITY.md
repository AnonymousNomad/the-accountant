# Requirements Traceability

Requirement IDs `SAH-REQ-NNN` derive from the v0.1 build directive (R1) and the research/skills
directive (R2). A requirement is **not** complete because code exists: it is complete only when
implementation **and** verification evidence exist. Evidence is the recorded output of the
command named in the Tests column, run by `npm run verify` / `npm run bench` and summarised in
`docs/EVIDENCE.md`.

Status values: `NOT VERIFIED` (pre-gate default) · `VERIFIED` · `PARTIAL` · `DEFERRED` ·
`OUT OF SCOPE`.
